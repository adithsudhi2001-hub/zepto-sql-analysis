# Zepto Inventory Analysis using SQL

## Project Overview
Analysis of Zepto (quick-commerce) product data using PostgreSQL to understand pricing, discounts, and inventory.

## Dataset
- 3,700+ product records
- Columns: category, name, MRP, discount percent, available quantity, selling price, weight, stock status

## Steps Followed
1. Data exploration (row count, nulls, categories, stock status)
2. Data cleaning (removed zero-price record, converted prices from paise to rupees)
3. Analysis using SQL queries
